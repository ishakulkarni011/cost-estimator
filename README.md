# Global Mobility Planner

A small Django tool that tells a company what it will cost, and how long it will take, to send an
employee from Zurich, Switzerland to work in London, UK.

The project is split into two folders:

- `backend/` holds the Django project, the tax rules, the calculation engine and the JSON API.
- `frontend/` holds the page, its styles and its JavaScript.

Work in progress: the full README follows once the app is complete.
